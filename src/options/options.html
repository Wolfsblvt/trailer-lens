Trailer Lens

Commit trailers, readable on GitHub commit pages.

General

Turning this off removes every panel from open GitHub tabs immediately.

Evidence

For example a line separated by a stray blank line — Git silently ignores it, Trailer Lens points at it.

Custom team conventions stay visible by default; the raw block always shows everything.

Hidden keys

Hide specific trailer keys from the friendly rows (for example change-id). The raw block is never filtered.

    Keys use letters, digits, and hyphens only.

    Privacy

    Trailer Lens reads commit messages from GitHub pages you are already viewing and shows their trailers on the same page. It stores nothing but these settings, sends nothing anywhere, and makes no network requests — no GitHub token, no API calls, no analytics, no telemetry, no remote code. Commit content never leaves the page.
