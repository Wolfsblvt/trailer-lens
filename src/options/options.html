    Device-local memory

    Off by default. When enabled, commit pages you visit remember their parsed trailers in Chrome's local extension storage on this device, so pages that only reference a commit (blame, releases, pull-request timelines) can show a small "remembered" chip for commits you have already seen. Nothing is synced or sent anywhere; entries are keyed by the full commit ID; oldest entries are removed automatically past 1500 commits or 3 MB in total. Remembered evidence stays until you purge it — turning this off stops remembering and showing, but keeps the data until purged.

    Privacy

    Trailer Lens reads commit messages from GitHub pages you are already viewing and shows their trailers on the same page. By default it stores nothing but these settings. If you explicitly enable device-local memory above, it additionally stores parsed trailer evidence from commit pages you visit — never whole commit messages — in this browser profile on this device, until you purge it or uninstall the extension. Nothing is ever synced, transmitted, or shared: no network requests, no GitHub token, no API calls, no analytics, no telemetry, no remote code.

    Reset restores the settings above to their defaults. It does not purge remembered evidence — that has its own controls in the memory section.
